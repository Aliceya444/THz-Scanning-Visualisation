# THz-Scanning-Visualisation
A python file 'skany.py' used for importing .meta, .txt and .npy files of the same name - it was important that GIFs, PNGs and other products created by this code is placed in directory next to imported files (easier accessibility when you have a lot of various data carefully organised). Imported files were saved in laboratory with various Terahertz equipment

Data measurement was taken with TeraSense 1024x1024 camera for Terahertz radiation and saved as text and numpy files - these can be read and visualised by my submitted code 'skany.py'. I needed all images taken in optical Z path (camera was moving forward from default position to position Z closer to setup starting point = radiation source). Each Z image shows propagating wavefront shape. So for fast viewing these images are also connected into GIF file.
Another file 'find_focus.py' tries to rank the Z slices by how well-focused they look. I decided to make my own four definitions (later normalised) on which python code suggests three highest scored Z images - to find sharpest real, inverted image produced by a magnifying optical system on this optical path. For each Z slice, it calculates several image measures: the mean of the brightest (highest voltage) 1% of pixels (topmean), the fraction of voltage distribution within 3 pixels of the brightest pixel, an RMS radius around that pixel, and horizontal and vertical FWHM.
